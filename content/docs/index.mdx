title: Introduction
description: A small collection of Discord utilities that run entirely in your browser, plus a JSON API that mirrors all of them.
---

aki's Discord Tools is 57 small utilities for Discord servers and users. Fancy text, snowflake
decoding, permission maths, invite inspection, webhook sending, emoji work.

Everything runs in your browser. There is no account, no database and no server holding
anything you type.
