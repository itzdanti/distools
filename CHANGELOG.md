# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html) for release tags. Each release also
has generated notes on the [releases page](https://github.com/itzdanti/distools/releases), built
from the commits in that release.

## [Unreleased]

### Added

- 57 browser-based Discord tools, from text styling and snowflake decoding to permission maths,
  emoji downloads and a synthesised soundboard.
- A static JSON API covering 53 of the tools, callable from a browser URL or the published
  `client.js` module, with generated OpenAPI and discovery documents.
- Documentation at `/docs`, built with Fumadocs, including a generated API reference.
- `DISTOOLS_CONFIG`, a single file describing the service name, deploy domain, repository,
  support and legal contacts, consumed by the app, the docs and the release workflow.
- Community files: contributing guide, code of conduct, security policy, support guide, this
  changelog, and an authors list.
- Issue and pull request templates, and a release workflow that builds the site and publishes a
  release with a generated changelog.
